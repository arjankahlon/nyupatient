Patient Surgery Guide: deploying to Netlify
===========================================

What's in this folder
  public/index.html            the whole site (content is in the CONTENT block at the top of the script)
  public/logo.png, icons       NYU Langone Orthopedics logo and home-screen icons
  netlify/functions/ics.mjs    makes "Add to Apple Calendar" open the calendar instead of a file
  netlify.toml                 tells Netlify where the site and function are
  serve.py                     local preview only (not used by Netlify)

Netlify setup (same as the tracker)
  Site: nyupatient (https://nyupatient.netlify.app), linked to github.com/arjankahlon/nyupatient, branch main.
  Auto publishing is LOCKED: every push builds, but nothing goes live until you click
  Publish deploy on that build (Netlify > Deploys). Builds that aren't published don't
  use credits; each publish does.

Check the calendar function after publishing
  https://nyupatient.netlify.app/api/ics should say "Bad request" (function is live).
  "Page not found" means it didn't deploy; Apple Calendar then falls back to a file download.

Links / QR codes
  https://YOUR-SITE.netlify.app/?s=lomas&p=dbr&d=2026-12-01
    s = surgeon    lomas
    p = procedure  scope (elbow arthroscopy), dbr (distal biceps), ucl, unt (ulnar nerve
                   transposition), epi (epicondylectomy), open (other open elbow)
    d = surgery date, YYYY-MM-DD
  All are optional. Leave d off for a generic surgeon/procedure QR code.
  The setup box on the site has a "For clinic staff" link builder.

Testing
  Add &today=MM-DD-YYYY to pretend it's a different day (e.g. &today=12-05-2026 to see the recovery view).
